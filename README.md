# 🚀 Sistema de Login & Cadastro Moderno

Este é um projeto de autenticação completo, desenvolvido com **Flask** no back-end e uma interface **Premium** com suporte a **Modo Escuro** no front-end.

## ✨ Funcionalidades

* **Design Profissional:** Interface limpa, responsiva e moderna.
* **Modo Escuro (Dark Mode):** Alternância inteligente com persistência (salva sua preferência).
* **Autenticação:** Sistema de cadastro e login integrado.
* **Feedback Visual:** Notificações via alertas e transições suaves.

---

## 🛠️ Tecnologias Utilizadas

* [Python](https://www.python.org/) + [Flask](https://flask.palletsprojects.com/)
* [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) & [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) (Variáveis CSS, Flexbox)
* [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) (Fetch API, LocalStorage)
